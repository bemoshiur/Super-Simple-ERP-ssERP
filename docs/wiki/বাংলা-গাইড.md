# বাংলা গাইড

ssERP একটি ফ্রি ও ওপেন-সোর্স (MIT লাইসেন্স) ERP, ইনভেন্টরি ও বিলিং সফটওয়্যার। এটি বিশেষভাবে সেইসব দোকানের জন্য
যেখানে প্রতিটি পণ্যের আলাদা **সিরিয়াল নম্বর বা IMEI** থাকে: মোবাইল ফোন, সিসিটিভি ক্যামেরা, রাউটার, ল্যাপটপ,
ইলেকট্রনিক্স। প্রতিটি ইউনিট ভেন্ডরের কাছ থেকে কেনা থেকে শুরু করে কাস্টমারের হাতে যাওয়া, এরপর ওয়ারেন্টি ও সার্ভিস
পর্যন্ত ট্র্যাক করা হয়।

```
ভেন্ডর -> ক্রয় -> ইনভেন্টরি -> বিক্রয় -> কাস্টমার -> ওয়ারেন্টি / সার্ভিস
```

> সংস্করণ **v0.1.0** (প্রথম পাবলিক রিলিজ)। সফটওয়্যারের ইন্টারফেস এখন ইংরেজিতে; বাংলা ইন্টারফেস
> [রোডম্যাপে](Roadmap) আছে। টাকার ঘরে `1,00,000`-এর মতো লাখ-কমা লেখা যায়, ডিফল্ট টাইম জোন `Asia/Dhaka`, আর বাংলা
> নাম ও নোট ঠিকভাবে দেখায়।

## যা লাগবে

- একটি **PostgreSQL ডাটাবেস**। সবচেয়ে সহজ হলো [Neon](https://neon.tech)-এর ফ্রি ডাটাবেস।
- নিচের যেকোনো একটি: একটি Vercel অ্যাকাউন্ট, অথবা **Node.js 20.9 বা নতুন** চালানো কম্পিউটার/সার্ভার, অথবা Docker।

## ইনস্টল করার তিনটি উপায়

### ক) Vercel + Neon (সার্ভার ছাড়াই, ক্লাউডে)

1. [README](https://github.com/bemoshiur/Super-Simple-ERP-ssERP#a-one-click-vercel--neon)-এর **Deploy with Vercel**
   বাটনে ক্লিক করুন।
2. তিনটি তথ্য দিন:
   - `DATABASE_URL`: Neon-এর কানেকশন স্ট্রিং (শেষে `?sslmode=require` রাখুন)।
   - `AUTH_SECRET`: কমপক্ষে ৩২ অক্ষরের র‍্যান্ডম লেখা (`openssl rand -base64 48`)।
   - `INSTALL_TOKEN`: কমপক্ষে ১৬ অক্ষরের র‍্যান্ডম লেখা (`openssl rand -hex 16`)।
3. ডিপ্লয় হলে `https://আপনার-অ্যাপ.vercel.app/install` খুলুন, টোকেন দিন, তারপর কোম্পানি ও অ্যাডমিনের তথ্য দিন
   (পাসওয়ার্ড কমপক্ষে ১০ অক্ষর)।
4. `/auth/login`-এ লগইন করুন।

ইনস্টল শেষ হলে `/install` চিরতরে বন্ধ হয়ে যায় (403)। বিস্তারিত: [Install on Vercel and Neon](Install-Vercel-and-Neon)।

> এই পথটি কোড অনুযায়ী লেখা, কিন্তু মেইনটেইনাররা এখনো পুরোটা চালিয়ে যাচাই করেননি। সমস্যা হলে ইস্যু খুলুন।

### খ) নিজের কম্পিউটারে বা সার্ভারে

```bash
git clone https://github.com/bemoshiur/Super-Simple-ERP-ssERP.git
cd Super-Simple-ERP-ssERP
./install.sh          # Node যাচাই, npm ci, তারপর npm run setup
npm run dev           # http://localhost:3000
```

`npm run setup` ডাটাবেস কানেকশন, কোম্পানির নাম, আপনার নাম, ইমেইল, মুদ্রার চিহ্ন (ডিফল্ট `৳`) ও পাসওয়ার্ড জিজ্ঞেস
করে, `.env.local` ফাইল লিখে দেয়, টেবিল তৈরি করে এবং প্রথম অ্যাডমিন বানায়। বিস্তারিত: [Install locally](Install-Local)।

### গ) Docker

```bash
cp .env.example .env     # DATABASE_URL, AUTH_SECRET ও INSTALL_TOKEN বসান
docker compose up -d --build
```

তারপর <http://localhost:3000/install> খুলুন। Docker ইমেজ এখনো মেইনটেইনাররা বিল্ড করে যাচাই করেননি।
বিস্তারিত: [Install with Docker](Install-Docker)।

## ইনস্টলের পর প্রথম কাজ

1. **Settings**-এ কোম্পানির নাম, ঠিকানা, ফোন, লোগো ও মুদ্রা দিন (ইনভয়েসে ছাপা হবে)।
2. **Accounts**-এ Cash, Bank ও bKash অ্যাকাউন্ট আগে থেকেই আছে; দরকার হলে নাম বা শুরুর ব্যালেন্স ঠিক করুন।
3. ক্যাটাগরি, ব্র্যান্ড ও প্রোডাক্ট যোগ করুন। যেসব পণ্যের সিরিয়াল/IMEI আছে সেগুলোতে **serial tracking** চালু করুন
   এবং ওয়ারেন্টির মাস দিন।
4. একজন ভেন্ডর যোগ করে **Purchases > New**-এ ক্রয় এন্ট্রি দিন; প্রতিটি ইউনিটের জন্য একটি করে সিরিয়াল লিখুন বা স্ক্যান
   করুন। পুরনো স্টক একসাথে তুলতে **Purchases > Import serials (CSV)** ব্যবহার করুন।
5. **Sales > New**-এ সিরিয়াল স্ক্যান করে বিক্রি করুন। একাধিক পেমেন্ট (যেমন কিছু নগদ, কিছু bKash) নেওয়া যায়;
   ওয়াক-ইন কাস্টমারকে পুরো টাকা দিতে হয়। A4 বা ৮০ মিমি রসিদ প্রিন্ট করুন।
6. **Serial Lookup**-এ সিরিয়াল লিখে বা স্ক্যান করে পুরো ইতিহাস দেখুন: কার কাছ থেকে কেনা, কার কাছে বিক্রি,
   ওয়ারেন্টি কবে শেষ।
7. **Users & Roles**-এ কর্মীদের Manager বা Salesman রোল দিয়ে যোগ করুন। Salesman ক্রয়মূল্য ও লাভ দেখতে পায় না।

বিস্তারিত (ইংরেজিতে): [First Steps After Install](First-Steps-After-Install)।

## ডেমো ডাটা দিয়ে দেখুন

নতুন ইনস্টলে `npm run seed:demo` চালালে নমুনা প্রোডাক্ট, ভেন্ডর, কাস্টমার, ক্রয়-বিক্রয় যোগ হয় (আলাদা "Demo"
অ্যাকাউন্টে)। তারপর **Serial Lookup**-এ `HIK123456789` খুঁজুন: ABC Electronics থেকে ২,০০০ টাকায় কেনা, Rahim-এর
কাছে ২,৮০০ টাকায় বিক্রি।

## অ্যাডমিনের পাসওয়ার্ড ভুলে গেলে

```bash
npm run admin:reset -- --email admin@yourshop.com
```

নতুন পাসওয়ার্ড (কমপক্ষে ১০ অক্ষর) চাইবে, ওই ইউজারকে সব জায়গা থেকে সাইন-আউট করবে এবং লগইন লকআউট তুলে দেবে।

## নিরাপত্তা ও ব্যাকআপ

- `.env` বা `.env.local` ফাইল কখনো গিটে কমিট করবেন না।
- Neon-এ নিয়মিত ব্রাঞ্চ বা পয়েন্ট-ইন-টাইম রিস্টোর ব্যবহার করুন; নিজের সার্ভারে `pg_dump` দিয়ে ব্যাকআপ নিন।
- নতুন সংস্করণে আপগ্রেডের আগে ব্যাকআপ নিন, তারপর `npm run db:migrate` চালান। বিস্তারিত:
  [Upgrading and Backups](Upgrading-and-Backups)।
- নিরাপত্তা সমস্যা পেলে পাবলিক ইস্যু না খুলে
  [প্রাইভেট রিপোর্ট](https://github.com/bemoshiur/Super-Simple-ERP-ssERP/security/advisories/new) করুন।
