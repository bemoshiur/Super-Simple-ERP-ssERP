# Getting help with ssERP

ssERP is a volunteer-maintained open-source project. There is no paid or private support, and no guaranteed response
time. These are the places to look and ask, in order:

1. **Documentation.** The [README](README.md) covers installation, configuration, upgrading and security. The
   [wiki](https://github.com/bemoshiur/Super-Simple-ERP-ssERP/wiki) has step-by-step guides (installation paths,
   first steps, serial tracking, POS, reports, branches), a **Troubleshooting** page and an **FAQ**.
   Its sources live in [docs/wiki/](docs/wiki/Home.md) if you prefer reading them in the repository.
2. **GitHub Discussions** (<https://github.com/bemoshiur/Super-Simple-ERP-ssERP/discussions>) for how-to questions,
   ideas and showing what you built. If Discussions is not enabled yet, open an issue with the **Question** form.
3. **Issues** (<https://github.com/bemoshiur/Super-Simple-ERP-ssERP/issues/new/choose>) for bugs and feature
   requests. Use the forms; they ask for the version, how you run ssERP and the steps to reproduce.

## Security problems

Never report a vulnerability in a public issue or discussion. Follow [SECURITY.md](SECURITY.md) and use a private
security advisory.

## Before you post

- Say which version or commit you run and how (Vercel + Neon, local, Docker), and which database.
- **Remove secrets.** Never paste `DATABASE_URL`, `AUTH_SECRET`, `INSTALL_TOKEN`, passwords, session cookies or real
  customer data. Replace them with `***`.
- Search existing issues and discussions first; a thumbs-up on an existing issue is more useful than a duplicate.

## Languages

English is preferred so that everyone can follow along. Questions in Bengali (বাংলা) are welcome too; a maintainer
or another community member may answer in English.
